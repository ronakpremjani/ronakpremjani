# RonakOS — Icons Directory

This directory is reserved for custom SVG icons that you might want to use in your GitHub Profile. 

The current design primarily uses Shields.io badges and external SVGs to keep the repository lightweight, but if you want to host your own custom icons, place them here.

## Usage in README.md

```html
<img src="./assets/icons/your-icon.svg" width="24" height="24" alt="Icon Name" />
```

## Recommended Icon Sources

If you need consistent, minimal icons that match the RonakOS aesthetic, check out:

- [Lucide Icons](https://lucide.dev/)
- [Radix Icons](https://icons.radix-ui.com/)
- [Feather Icons](https://feathericons.com/)

Ensure that any icons you add use `currentColor` for fills/strokes so they can adapt to different contexts, or strictly use the RonakOS palette colors (`#F8FAFC`, `#60A5FA`, `#3FB950`, `#8B949E`).
