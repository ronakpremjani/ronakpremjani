# Widgets Reference

All dynamic widgets used in this profile, with configuration details.

## GitHub Stats Card
**Provider:** [github-readme-stats](https://github.com/anuraghazra/github-readme-stats)

```
https://github-readme-stats.vercel.app/api
  ?username=ronak
  &show_icons=true
  &hide_border=true
  &bg_color=0d1117
  &title_color=F8FAFC
  &icon_color=60A5FA
  &text_color=8B949E
  &ring_color=60A5FA
```
